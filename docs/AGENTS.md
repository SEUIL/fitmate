# AGENTS.md

## Docs 작업 규칙

`docs/` 아래에서 문서를 작성하거나 수정할 때는 [문서-작성-규칙.md](./00-project/문서-작성-규칙.md)를 따른다.

## 핵심 원칙

- 대상 파일을 먼저 읽고 필요한 최소 범위만 수정한다.
- `00-project/1차기획/` 자료는 명시 요청 없이 수정하지 않는다.
- 발표 준비 문서는 `00-project/`, `01-spec/`, `02-technical/`, `03-qa/`에 둔다.
- 상태가 `확정`인 문서는 사용자 확인 없이 수정하지 않는다.
- 새 문서 생성 전 같은 이름의 파일이 이미 있는지 확인한다.
- 문서 변경 후 가능한 Markdown 검사 또는 관련 검증을 실행한다.

## 금지사항

- 회의 결정과 Action Item을 `00-project/결정-회의-로그.md` 밖에 분산해 기록하지 않는다.
- 발표와 직접 관련 없는 새 문서 분류를 만들지 않는다.
- secret, token, password, 개인정보를 문서에 기록하지 않는다.
