# FitMate 기능 구현 백로그

- 작성일: 2026-09-03
- 최종 수정일: 2026-09-03
- 버전: 0.2
- 상태: 검토 중
- 기능 기준: `docs/프로젝트제출용/3주차/기능명세서_v1.2.pdf`
- 순서 기준: `docs/01-spec/기능-개발-우선순위.md`

## 1. 사용 원칙

- 개발자 또는 Codex는 작업 ID를 위에서 아래 순서로 구현한다.
- 기능, 입력값, 상태와 정책은 기능명세서 v1.2에 있는 내용만 사용한다.
- 이 문서의 작업 ID와 개발 순서는 구현을 위해 재배치한 것이며 기능명세서 원문 항목은 아니다.
- 기능명세서에 없는 API 경로, 요청·응답 필드, 검색, 정책은 이 문서에서 새로 정하지 않는다.
- 관리자 기능과 광고 및 제휴 기능은 구현 범위에서 제외한다.

## 2. 기능 구분

| 구분 | 기능명세서의 의미 |
|---|---|
| 혼자 운동하기 | 개인 루틴을 선택하거나 직접 구성하고 개인 운동 세션을 생성하는 진입 방식 |
| 같이 운동하기 | 메이트 모집, 참가 확정 후 참가자별 개인 운동 세션을 생성하는 진입 방식 |
| 공통 운동 모듈 | 혼자 운동과 같이 운동이 함께 사용하는 운동 진행, 기록, Samsung Health Data, 리포트 기능 |
| 일반 커뮤니티 | 팔로우, 일반 게시물, 피드, 좋아요와 댓글 기능 |

같이 운동하기의 모집 게시물과 일반 커뮤니티 게시물은 서로 다른 기능으로 구현한다.

## 5. WORKOUT-COMMON 공통 운동 모듈

### 5.1 기본 구조

- 혼자 운동하기와 같이 운동하기에서 동일한 운동 진행 모듈을 사용한다.
- 진입 유형은 `SOLO`와 `MATE`로 구분한다.
- 같이 운동하더라도 운동 세션, 운동 기록, Samsung Health Data와 리포트는 참가자별로 생성한다.
- 모집 게시물과 모임 정보만 참가자 사이에서 공유한다.
- 개인 심박수, 칼로리와 상세 운동 기록은 본인에게만 공개한다.
- 사용자가 선택한 요약 정보만 공유할 수 있다.

### 5.2 세션 상태 구현 순서

| 순서 | 상태 | 의미 |
|---|---|---|
| 1 | `READY` | 운동 시작 전 |
| 2 | `IN_PROGRESS` | 운동 중 |
| 3 | `PAUSED` | 일시정지 |
| 4 | `SYNC_WAITING` | Samsung Health Data 동기화 대기 |
| 5 | `REVIEW_REQUIRED` | 외부 운동 기록 확인 필요 |
| 6 | `COMPLETED` | 운동 및 리포트 생성 완료 |
| 7 | `CANCELED` | 운동 취소 |

### 5.3 공통 기능 구현 순서

| 순서 | 작업 ID | 기능명세서 내용 |
|---|---|---|

| 2 | `WORKOUT-COMMON-02` | 워밍업과 스트레칭 안내 |
| 3 | `WORKOUT-COMMON-03` | 운동 시작, 일시정지, 재시작, 종료 |
| 4 | `WORKOUT-COMMON-04` | 운동 추가, 삭제, 순서 변경 |
| 5 | `WORKOUT-COMMON-05` | 세트별 중량, 반복 횟수, RPE, 메모 기록 |

## 7. REPORT 개인 리포트

### 7.1 기본 리포트

- FitMate에서 직접 기록한 운동 시간, 종목, 세트, 중량, 반복 횟수, RPE, 메모

- 총 세트, 총 반복 수, 총 볼륨과 목표 달성 여부

### 7.2 Samsung Health 상세 리포트

- 기본 리포트 전체 항목
- Samsung Health 운동 종류와 측정 시간
- 거리, 페이스, 걸음 수, 칼로리
- 평균, 최저, 최고 심박수와 심박 구간
- 기기에서 제공된 경우 경로, 속도, 케이던스와 고도

외부 측정값은 소비자용 웰니스 정보이며 의료 진단이나 확정적인 건강 판단에 사용하지 않는다.

## 8. SAMSUNG-HEALTH Samsung Health Data

### 8.1 사용 설정

- Samsung Health Data 연동은 선택 기능이다.
- 계정 설정에서 연결, 연결 해제와 데이터 권한을 관리한다.
- 연결된 사용자도 운동 시작 전에 이번 운동에서 사용할지 선택한다.
- 같이 운동하는 참가자도 각자 사용 여부를 설정한다.
- 사용하지 않거나 로그가 없어도 FitMate 자체 기록으로 운동을 완료할 수 있다.

### 8.2 사용 시 구현 순서

| 순서 | 작업 ID | 기능명세서 내용 |
|---|---|---|
| 1 | `SAMSUNG-HEALTH-01` | 이번 운동에서 Samsung Health Data 사용 선택 |
| 2 | `SAMSUNG-HEALTH-02` | 연결, 권한, 동기화 가능 상태 확인 |
| 3 | `SAMSUNG-HEALTH-03` | 사용자가 워치 또는 Samsung Health에서 운동 시작 |
| 4 | `SAMSUNG-HEALTH-04` | 기기에서 운동 시작 확인 후 FitMate 운동 시작 |
| 5 | `SAMSUNG-HEALTH-05` | 공통 운동 모듈에서 운동 진행 |
| 6 | `SAMSUNG-HEALTH-06` | 운동 종료 시 기기의 운동 종료 안내 |
| 7 | `SAMSUNG-HEALTH-07` | 기기 운동 종료 후 FitMate 운동 완료 선택 |
| 8 | `SAMSUNG-HEALTH-08` | 동기화 후 최근 운동 로그 조회 |
| 9 | `SAMSUNG-HEALTH-09` | 운동 종류와 시작·종료 시간 기준으로 세션과 로그 연결 |
| 10 | `SAMSUNG-HEALTH-10` | 불확실한 기록은 사용자가 선택하거나 연결하지 않음 |
| 11 | `SAMSUNG-HEALTH-11` | Samsung Health Data를 반영한 상세 리포트 생성 |

### 8.3 미사용 시 구현 순서

| 순서 | 작업 ID | 기능명세서 내용 |
|---|---|---|
| 1 | `SAMSUNG-HEALTH-OFF-01` | 미사용 선택 또는 미연결 상태로 운동 시작 |
| 2 | `SAMSUNG-HEALTH-OFF-02` | 공통 운동 모듈에서 직접 기록 |
| 3 | `SAMSUNG-HEALTH-OFF-03` | FitMate 자체 기록으로 기본 리포트 생성 |

### 8.4 로그 동기화와 연결

- 워치의 운동 종료 로그는 Samsung Health에 동기화된 후 FitMate 앱이 조회해 서버로 전송한다.
- 로그가 늦게 들어오면 기본 리포트를 먼저 생성하고 동기화 완료 후 상세 리포트로 갱신한다.
- 운동 종류, 시작·종료 시각과 허용 시간 범위를 사용해 운동 세션을 매칭한다.
- 같은 시간대에 여러 로그가 있으면 자동 확정하지 않고 사용자 확인을 요청한다.
- 원본 레코드 ID, 출처 앱과 수정 시각을 저장해 중복 등록을 방지한다.
- Samsung Health에서 제공하지 않은 필드는 누락을 허용한다.

- 맞팔이 아니면 목록, 검색과 상세 화면에 노출하지 않는다.
- 맞팔이 해제되면 조회 권한도 즉시 사라진다.

## 16. DM 개인 메시지

### 16.1 발신 정책

- 공개 계정은 관계가 없어도 일반 DM을 전송할 수 있다.
- 비공개 계정은 맞팔이면 일반 DM을 전송할 수 있다.
- 비공개 계정의 일방 팔로워는 메시지 요청을 전송할 수 있다.
- 비팔로워이면 DM을 전송할 수 없다.

## 17. BLOCK-REPORT 차단과 신고

### 17.1 차단

- 차단된 사용자는 상대방의 프로필과 게시물을 조회할 수 없다.
- 차단된 사용자는 팔로우, DM과 메시지 요청을 할 수 없다.
- 기존 DM은 차단한 사용자의 화면에서 숨긴다.
- 차단 목록에서 차단을 해제할 수 있다.

### 17.2 신고

신고 대상은 사용자 프로필, 커뮤니티 게시물, 메이트 구인 게시물, 댓글과 DM 메시지다.

신고 사유는 다음과 같다.

- 부적절한 콘텐츠
- 욕설 또는 괴롭힘
- 광고 또는 스팸
- 사칭
- 노쇼 또는 반복적인 일정 취소
- 기타

신고 상태는 `RECEIVED`, `REVIEWING`, `RESOLVED`, `REJECTED`를 사용한다. 처리 결과와 필요한 범위의 사유를 신고자에게 알리고 제재 대상자에게 이의신청 절차를 제공한다.

## 20. PRIVACY 개인정보와 보안

기능을 구현할 때 다음 기능명세서 내용을 함께 적용한다.

- 비밀번호를 복구 가능한 형태로 저장하지 않는다.
- 인바디와 Samsung Health Data 등 건강 관련 정보는 일반 개인정보와 구분해 접근을 제한한다.
- Samsung Health Data 연결과 권한 해제를 제공한다.
- 서버에 저장된 외부 운동 기록 삭제 기능을 제공한다.
- 외부 운동 기록의 원본 출처와 사용자 동의 상태를 저장한다.
- 같이 운동한 참가자에게 개인 심박수, 칼로리와 경로 등 건강정보를 기본 공개하지 않는다.
- 위치정보의 처리 목적, 보유기간, 파기와 동의 철회를 안내한다.
- 파일 업로드 시 확장자, 용량과 악성 파일을 검사한다.
- 로그인, DM과 게시물 작성 API에 호출 횟수 제한을 적용한다.
- 주요 보안 이벤트를 기록한다.
- 백업, 복구, 보유기간과 파기 정책을 수립한다.
- 개인정보 처리방침과 이용약관을 공개한다.
- 개인정보 삭제와 동의 철회 기능을 제공한다.
- 관련 법률과 최종 동의 문구는 출시 전 별도 법률 검토를 진행한다.
