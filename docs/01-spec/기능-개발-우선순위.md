# FitMate 기능 개발 우선순위

- 작성일: 2026-09-03
- 최종 수정일: 2026-09-07
- 버전: 0.4
- 상태: 검토 중
- 기능 기준: `docs/프로젝트제출용/3주차/기능명세서_v1.2.pdf`

## 1. 문서 기준

기능과 정책은 기능명세서 v1.2에 적힌 내용만 사용한다.
기능명세서 v1.2에는 개발 시점과 우선순위가 없으므로, 아래 순서는 팀에서 정한 개발 방향인
`회원가입·계정 -> 혼자 운동하기 -> 같이 운동하기 -> 일반 커뮤니티`를 적용한 것이다.

세부 작업 순서는 [`기능-구현-백로그.md`](./기능-구현-백로그.md)를 따른다.

## 2. 제외 범위

- 관리자 기능 전체
- 광고 및 제휴 기능 전체
- 게시물 연동 오픈 단체 채팅
- 초대 기반 비공개 단체 채팅
- 참가 확정자 전용 단체 채팅
- Galaxy 기기와 FitMate 앱의 직접 Bluetooth 통신
- 워치 심박수 실시간 스트리밍
- 실시간 위치 공유

| 1 | P0 | 회원가입, 로그인, 운동 프로필, 계정 관리, 동의 |

| 7 | P1 | 같이 헬스, 같이 러닝, 나머지 운동 카테고리 |

## 4. P0 확정 범위

P0는 다음 핵심 흐름을 완성하는 범위다.

`가입 -> 프로필 작성 -> 혼자 운동 선택 -> 헬스 루틴 선택 -> Samsung Health Data 사용 여부 선택 -> 공통 운동 모듈 -> 개인 리포트`

혼자 운동 선택 화면의 기본 종목은 헬스와 러닝이다. P0 종목 사전에서 두 종목을 모두 활성화하고 Android 러닝 화면으로 진입할 수 있게 한다. 러닝 기록의 서버 저장, 동기화와 리포트는 P1에서 구현한다.

Samsung Health Data는 선택 기능이므로 연결하거나 사용하지 않아도 FitMate 자체 기록으로 운동을 완료하고 기본 리포트를 생성할 수 있어야 한다.
