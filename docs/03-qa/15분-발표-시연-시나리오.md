# FitMate 15분 Android 앱 시연 시나리오

- 작성일: 2026-09-09
- 최종 수정일: 2026-09-10
- 버전: v1.2
- 상태: 검토 중
- 대상: Android 앱 발표 시연
- 발표 시간: 15분

## 1. 시연 목표

로그인은 짧게 통과하고, FitMate의 핵심인 운동 기록을 가장 자세히 보여 준다. 후반에는 인바디, 메이트와 커뮤니티·DM이 실제 사용자 흐름으로 이어지는 모습을 보여 준다.

백엔드 콘솔, Apidog, API 응답과 소스 코드는 열지 않는다. Android 앱에서 저장한 뒤 화면을 다시 열어 결과가 유지되는 모습으로 서버 연동을 전달한다.

핵심 메시지는 아래 한 문장으로 통일한다.

> FitMate는 운동을 계획하고 기록해 변화를 확인하며, 그 기록을 메이트와 커뮤니티로 연결하는 앱입니다.

## 2. 발표 시간 배분

| 시간 | 화면 | 핵심 시연 |
|---|---|---|
| 0:00–0:30 | 로그인·홈 | 로그인 성공과 전체 메뉴 |
| 0:30–5:20 | 헬스 | 루틴, 운동 구성 변경, 세트 기록, 휴식, 리포트 |
| 5:20–6:40 | 러닝 | 목표, 예시 GPS, 랩, 서버 저장 |
| 6:40–7:15 | 운동 기록 | 헬스·러닝 통합 목록과 상세 |
| 7:15–8:40 | 인바디 | 사진 판독, 사용자 검수, 변화 기록 |
| 8:40–10:50 | 메이트 | 필터, 상세 조건, 문의, 참가 상태 |
| 10:50–13:50 | 커뮤니티·소셜·DM | 다중 사진, 좋아요·댓글, 팔로우, DM, 알림 |
| 13:50–15:00 | 홈·마무리 | 구현 범위 요약과 핵심 가치 |

운동 구간에 약 6분 30초를 사용하고, 로그인과 화면 전환 설명은 최소화한다.

## 3. 발표 직전 준비

### 3.1 계정과 데이터

- 발표용 계정 A로 로그인할 수 있게 준비한다.
- 계정 A에는 이전 헬스·러닝·인바디 기록을 각각 1개 이상 준비한다.
- 추천 루틴과 내 루틴이 모두 조회되는지 확인한다.
- 운동 추가·대체 시 선택할 운동 이름을 미리 정한다.
- 메이트 모집글은 계정 A가 참가 신청한 상태 또는 참가 확정 상태인 글을 준비한다.
- 문의 메시지가 1개 이상 있는 메이트 글을 준비한다.
- 커뮤니티에는 사진 여러 장이 첨부된 내 게시물과 다른 사용자의 게시물을 준비한다.
- 팔로우된 사용자와 기존 DM 대화방을 준비한다.
- 좋아요·댓글·DM으로 생성된 읽지 않은 알림을 1개 이상 준비한다.

### 3.2 기기와 서버

- 최신 Debug 앱, 백엔드와 MySQL이 정상 실행 중인지 확인한다.
- 필요한 환경에서는 `adb reverse` 연결을 확인한다.
- 테스트용 예시 GPS가 보이는 Debug 빌드를 사용한다.
- 개인정보가 없는 인바디 예시 이미지와 커뮤니티용 이미지 3장을 갤러리 첫 화면에 둔다.
- 인바디 공급자가 `OPENAI`인지 `MOCK`인지 발표 전에 확인한다.
- 방해 금지 모드와 화면 회전 고정을 켠다.

### 3.3 시간 절약용 준비

- 로그인 이메일은 미리 입력해 두고 비밀번호 입력과 로그인 버튼만 보여 준다.
- 헬스 입력값은 `30kg × 12회, RPE 7`로 고정한다.
- 러닝은 `테스트용 예시 GPS → 6분 진행` 순서로 바로 실행한다.
- 인바디 AI 판독이 지연될 수 있으므로 완료된 판독 기록도 하나 준비한다.
- 메이트 새 글 작성과 두 계정 간 수락 처리는 화면을 모두 입력하지 않고, 준비된 글의 저장 결과와 상태 변화를 중심으로 보여 준다.
- 커뮤니티 글은 사진 3장이 첨부된 상태로 미리 저장하고, 발표 중에는 사진 제거 수정과 재조회에 집중한다.
- 회원가입, 비밀번호 변경, 회원 탈퇴, 루틴 전체 CRUD, 차단과 신고는 15분 본 시연에서 제외한다.

## 4. 발표자용 전체 대본

대괄호 안의 내용은 말하지 않고 화면에서 수행한다.

### 0:00–0:30 로그인과 홈

[이메일이 입력된 로그인 화면에서 비밀번호를 입력하고 로그인한다.]

> 발표용 계정으로 로그인하겠습니다. FitMate는 계정별 운동 기록과 소셜 데이터를 서버에 저장합니다.

[홈 화면에서 운동 시작, 메이트, 커뮤니티와 프로필 메뉴를 빠르게 가리킨다.]

> 로그인과 회원가입 상세는 줄이고, 핵심 운동 기록부터 보여드리겠습니다.

### 0:30–1:20 루틴 선택

[홈 → 운동 시작 → 헬스로 이동한다. 추천 루틴, 기본 루틴, 내 루틴 탭을 빠르게 전환한다.]

> 헬스에서는 사용자 목표에 맞는 추천 루틴, 기본 템플릿과 직접 저장한 내 루틴을 사용할 수 있습니다.

[추천 루틴 하나를 열어 운동 구성과 오늘의 분할·운동 부위를 보여 준 뒤 시작한다.]

> 루틴을 선택하면 오늘 수행할 운동과 목표 세트가 서버 세션으로 생성됩니다.

### 1:20–2:45 운동 구성 변경

[운동 목록에서 `운동 목록에서 선택`을 누르고 준비한 운동을 추가한다.]

> 운동을 시작한 뒤에도 서버 운동 목록에서 종목을 추가할 수 있습니다.

[아직 세트를 기록하지 않은 운동을 선택해 다른 운동으로 대체한다.]

> 장비 사용이 어렵거나 계획을 바꾸고 싶으면 기록 전 운동을 대체할 수 있습니다.

[위·아래 버튼으로 운동 순서를 한 번 변경한다. 불필요한 운동 하나를 삭제한다.]

> 순서 변경과 삭제도 서버에 저장되며, 변경 뒤 전체 세션을 다시 불러와 최신 상태를 유지합니다.

[변경된 운동 목록을 잠깐 멈춰 보여 준다.]

### 2:45–4:05 세트 기록과 휴식

[첫 운동을 선택하고 30kg, 12회, RPE 7과 짧은 메모를 입력한다. 세트 기록을 누른다.]

> 세트마다 중량, 반복 횟수, 체감 강도인 RPE와 메모를 저장합니다.

[완료 표시와 휴식 타이머를 보여 준다.]

> 서버 저장에 성공하면 완료 세트가 반영되고 기기의 휴식 타이머가 시작됩니다.

[같은 세트를 32.5kg으로 수정해 다시 저장한다. 이전 기록 비교 영역이 있으면 가리킨다.]

> 잘못 입력한 세트는 수정할 수 있고, 이전 동일 운동 기록과 비교해 오늘 중량을 정할 수 있습니다.

[운동 일시정지와 재개를 한 번씩 누른다.]

> 운동 중단과 재개 상태도 서버 세션에 반영됩니다.

### 4:05–5:20 운동 완료와 리포트

[운동 종료 → 리포트 보기를 누른다.]

> 시연 시간상 한 세트만 기록하고 종료하겠습니다. 실제 운동에서는 같은 방식으로 모든 세트를 누적합니다.

[완료 세트, 총 반복, 총 볼륨, 최대 중량과 이전 기록 대비를 순서대로 가리킨다.]

> 완료 리포트는 서버에 저장된 세트를 기준으로 운동 수, 완료 세트, 총 반복과 총 볼륨을 계산합니다. 운동별 최대 중량과 이전 기록 대비 변화도 바로 확인할 수 있습니다.

> FitMate의 핵심은 단순 타이머가 아니라 계획한 운동을 구체적으로 기록하고 다음 운동의 기준으로 만드는 것입니다.

### 5:20–6:40 러닝

[홈 → 운동 시작 → 러닝으로 이동한다. 자유, 거리, 시간, 페이스와 인터벌 목표를 빠르게 보여 주고 거리 목표를 선택한다.]

> 러닝은 목적에 따라 자유, 거리, 시간, 목표 페이스와 인터벌을 선택할 수 있습니다.

[테스트용 예시 GPS를 켜고 러닝 시작 → 6분 진행을 누른다.]

> 오늘은 실내 발표라 Debug 전용 예시 GPS를 사용합니다. 실제 야외 사용에서는 기기 GPS를 이용합니다.

[거리, 시간, 평균 페이스와 1km 랩을 가리킨다. 종료 후 RPE, 컨디션과 메모를 입력해 저장한다.]

> 종료할 때 랩과 체감 강도, 컨디션, 메모를 함께 서버에 저장합니다.

### 6:40–7:15 통합 운동 기록

[프로필 → 운동 기록에서 전체, 헬스, 러닝 필터를 빠르게 전환한다. 방금 저장한 기록 하나를 연다.]

> 헬스와 러닝 기록은 한곳에서 최신순으로 확인하고 종목별로 나눠 볼 수 있습니다. 앱을 다시 열어도 서버에 저장된 상세 기록을 조회합니다.

### 7:15–8:40 인바디

[프로필 → 인바디 기록으로 이동해 최근 기록과 변화 차트를 보여 준다.]

> 체중, 골격근량과 체지방률을 직접 입력하거나 결과지 사진에서 읽어 변화로 관리합니다.

[새 기록 → 사진 선택으로 익명 결과지를 선택한다. 판독 완료가 빠르면 결과로 이동하고, 지연되면 준비된 완료 기록을 연다.]

> 이미지는 서버에 업로드되고 백엔드가 판독합니다. 오늘 판독 공급자는 준비 단계에서 확인한 OpenAI 또는 Mock입니다.

[판독값 하나를 수정하고, 확인 필요 항목과 사용자 검수 체크를 보여 준다.]

> 판독값을 자동 확정하지 않습니다. 사용자가 원본과 비교해 수정하고 마지막 검수 후 저장합니다.

[저장된 상세 또는 기존 상세를 열어 주요 수치와 변화가 유지되는지 보여 준다.]

> 이 기능은 의료 진단이 아니라 운동 변화 기록을 돕는 기능입니다.

### 8:40–9:35 메이트 목록과 상세

[하단 메이트 → 필터를 열어 종목, 난이도, 지역과 날짜 조건을 보여 주고 적용한다.]

> 메이트에서는 종목과 지역, 날짜, 난이도, 모집 상태를 서버 조건으로 검색합니다.

[준비된 모집글을 열어 일정, 장소, 난이도, 인원, 비용과 종목별 조건을 가리킨다.]

> 일반 게시글과 달리 실제 약속에 필요한 조건을 구조화해 빠르게 비교할 수 있습니다.

### 9:35–10:50 메이트 문의와 참가

[문의하기 → 준비된 문의방을 열어 메시지와 답장을 보여 준다. 가능하면 짧은 메시지 하나를 전송한다.]

> 모집글별 문의방에서 메시지를 보내고 읽음 상태를 관리합니다. 메시지는 재조회해도 중복되지 않도록 처리합니다.

[상세로 돌아가 참가 신청 상태 또는 참가 확정 상태를 보여 준다. 확정 상태라면 집결 위치를 가리킨다.]

> 참가 신청은 작성자가 수락하거나 거절할 수 있습니다. 정확한 집결 위치는 작성자와 확정 참가자에게만 공개됩니다.

[내 모집글의 메뉴를 잠깐 열어 수정·신청 관리·마감·취소 동작이 있음을 보여 주고 실행하지 않는다.]

> 작성자는 모집글 수정, 신청 관리, 모집 마감과 취소까지 처리할 수 있습니다.

### 10:50–12:15 커뮤니티 게시물과 다중 사진

[하단 커뮤니티에서 전체, 팔로잉과 내 게시물 탭을 전환한다. `게시물 더 보기`가 있으면 한 번 누른다.]

> 커뮤니티는 전체, 팔로잉과 내 게시물을 구분하고, 더 보기로 다음 페이지를 중복 없이 불러옵니다.

[미리 준비한 사진 3장 게시물을 열어 좌우로 사진을 확인한다. 게시물 수정에서 사진 1장을 제거하고 본문을 짧게 바꿔 저장한다.]

> 게시물에는 사진을 여러 장 첨부할 수 있습니다. 수정할 때 기존 서버 사진을 유지하거나 일부만 제거할 수 있습니다.

[다른 화면으로 갔다가 게시물을 다시 열어 사진 2장과 수정 본문이 유지되는지 보여 준다.]

> 다시 조회한 뒤에도 본문, 공개 범위와 사진이 서버에서 그대로 표시됩니다.

### 12:15–12:55 좋아요와 댓글

[다른 사용자의 게시물에 좋아요를 누르고 댓글을 하나 작성한다. 댓글 목록을 닫았다 다시 열어 작성 내용을 보여 준다.]

> 좋아요와 댓글도 서버에 반영되며, 상대 사용자의 알림으로 이어집니다.

[게시물 공개 범위 선택 영역을 잠깐 보여 준다.]

> 게시물은 전체 공개와 맞팔 공개를 선택할 수 있습니다.

### 12:55–13:30 프로필, 팔로우와 DM

[게시물 작성자 프로필을 열어 팔로우 상태, 팔로워·팔로잉 수를 보여 준다.]

> 공개 계정은 바로 팔로우하고, 비공개 계정은 요청과 수락 과정을 거칩니다.

[준비된 DM 대화방을 열어 텍스트와 사진 메시지를 보여 주고 짧은 답장을 보낸다.]

> 맞팔 사용자는 바로 대화하고, 그 외 관계의 첫 메시지는 요청으로 분리됩니다. 사진도 서버에 업로드해 대화에 연결할 수 있습니다.

### 13:30–13:50 알림과 안전 기능

[알림 목록을 열어 좋아요·댓글·DM 또는 메이트 알림 하나를 누르고 관련 화면으로 이동한다.]

> 앱 내 알림은 관련 게시물, 사용자, 대화나 메이트 화면으로 연결됩니다.

[프로필 또는 게시물 메뉴의 신고·차단 항목은 열지 않고 위치만 가리킨다.]

> 차단과 신고 기능도 제공하며, 신고는 접수까지 구현되어 있습니다. 관리자 심사와 Push 알림은 이번 시연 범위가 아닙니다.

### 13:50–15:00 마무리

[홈으로 돌아가고 이후에는 조작하지 않는다.]

> 지금까지 FitMate의 전체 사용자 흐름을 보여드렸습니다. 헬스에서는 루틴을 선택하고 운동 구성을 현장에서 바꾸며 세트별 기록과 리포트를 남깁니다. 러닝과 인바디까지 함께 관리해 사용자의 변화를 확인합니다.

> 기록은 개인에게만 머무르지 않습니다. 조건에 맞는 메이트를 찾고, 문의와 참가로 실제 운동 약속을 만들며, 커뮤니티와 팔로우, DM을 통해 다른 사용자와 이어집니다.

> FitMate의 핵심은 계획, 기록, 변화, 연결입니다. 이상으로 시연을 마치겠습니다. 감사합니다.

## 6. 시간이 밀릴 때 생략 순서

1. 로그인 후 홈 메뉴 설명을 생략하고 바로 헬스로 이동한다.
2. 러닝 목표 종류 설명을 줄이고 거리 목표만 선택한다.
3. 운동 기록 상세를 생략하고 목록의 헬스·러닝 필터만 보여 준다.
4. 인바디 사진 선택 대신 준비된 판독 결과의 사용자 수정 화면부터 시작한다.
5. 메이트 필터 종류 설명을 줄이고 준비된 상세와 문의방만 보여 준다.
6. 커뮤니티의 전체·팔로잉 탭 전환과 더 보기를 생략한다.
7. 프로필 팔로우 설명을 생략하고 기존 DM 대화방만 연다.
8. 헬스 운동 구성 변경, 세트 저장과 완료 리포트는 끝까지 유지한다.

## 9. 마지막 리허설 체크

- 전체 시연을 13분 30초 안에 끝내고 1분 30초를 전환 지연에 남긴다.
- 로그인부터 마무리까지 화면 전환 경로를 한 번에 연습한다.
- 헬스 구성 변경은 `추가 → 대체 → 순서 변경 → 삭제` 순서로 고정한다.
- 세트 입력값은 30kg × 12회, RPE 7로 고정한다.
- 세트 저장 직후 완료 표시와 휴식 타이머를 가리킨다.
- 리포트는 완료 세트 → 총 반복 → 총 볼륨 → 이전 대비 순서로 가리킨다.
- 테스트용 GPS라고 먼저 밝힌 뒤 6분 진행을 누른다.
- 인바디 공급자가 OPENAI인지 MOCK인지 확인한다.
- 인바디 사진에는 이름, 생년월일, 회원번호와 QR 코드가 없어야 한다.
- 메이트 글의 현재 신청 상태와 집결 위치 공개 상태를 확인한다.
- 커뮤니티 수정용 게시물에 사진 3장이 표시되는지 확인한다.
- 기존 DM 대화방과 읽지 않은 앱 내 알림을 준비한다.
- 삭제, 회원 탈퇴, 차단과 신고는 본 시연 중 실행하지 않는다.
- 마지막 1분에는 홈 화면에서 조작 없이 결론만 말한다.
