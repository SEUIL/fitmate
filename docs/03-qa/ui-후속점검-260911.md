- 최종 수정일: 2026-09-13
- 버전: v1.1
- 상태: 검토 중
- 범위: 홈 워드마크, 가로 화면·키보드, 큰 글자, 주요 이동과 운동 저장 회귀

## 적용 결과

홈 상단 FitMate 글자 옆 심볼과 배경 상자를 제거했다. 글자·알림·DM 버튼은 유지한다. 시작 화면과 앱 아이콘은 이번 변경 대상이 아니다.

실기기 가로 화면에서 Samsung 숫자 키보드를 열면 운동 진행 화면의 고정 상단·기록 버튼이 남은 높이를 차지해 입력란이 보이지 않는 문제를 재현했다. 가로 화면에서 키보드가 열린 동안 상단 동작과 세트 기록 버튼을 본문 스크롤에 배치했다. 중량·횟수·RPE 입력 후 아래로 스크롤해 기록할 수 있고, 키보드를 닫으면 기존 고정 배치로 돌아온다. 기록 검증·세트 수정·휴식·종료 저장 로직은 동일하다.

Samsung Health 내부 UI, API, 권한 정책, DB 스키마는 변경하지 않았다.

## 검증 결과

연결된 Samsung SM-S947N에서 격리 패키지 `com.fitmate.app.dev.records`로 실행했다. 가로 검사는 실제 화면을 회전하고 실제 키보드를 사용했다. 검사가 끝나면 회전 고정을 해제한다. 큰 글자는 테스트 Compose 환경에 fontScale 2.0을 제공했으며 기기 전체 글자 설정을 변경하지 않았다.

| 검사 | 결과 | 확인한 동작 |
|---|---|---|
| 새 가로 화면 검사 | 4개 통과 | 홈 큰 글자·6개 이동 콜백, 운동 입력·세트 기록·전체 운동 보기와 뒤로가기, 각 라이트/다크 |
| 기존 UI 회귀 | 22개 통과 | 홈·운동 8, 개인 운동 4, 메이트 7, 큰 글자 커뮤니티/인바디/계정 설정 각 1 |
| 실제 서버 연동 | 4개 통과 | 두 테마에서 헬스 루틴 수정→세트 기록/수정→이어하기→완료/이력, 러닝 설정→종료→저장/재조회 |
| 단위 테스트 | 58개 통과 | 실패·오류·건너뜀 0 |
| Debug 빌드·설치 | 성공 | 일반 패키지 `com.fitmate.app.dev`, 설치 시각 2026-09-11 03:32:34 |

실기기 검사 합계는 서로 다른 30개다. 회전 애니메이션 중 찍힌 홈 증빙을 보완해 홈 검사 2개를 추가 재실행했다. 초기 가로 입력 검사 실패는 위 UI 수정으로 해결했다. 테스트의 동명 제목 선택자는 스크롤 본문과 고정 상단을 구분하도록 보정했다.

실제 서버 검사는 새 합성 계정에서 수행했다. 사용자의 기존 기록·로그인·동의는 보존했다. 일반 앱에서도 홈 워드마크와 로고 제거, 메이트 헬스 선택·오늘 필터 적용, 커뮤니티·프로필·홈 이동을 확인했다. 종료 시 홈 화면이며 백엔드 health는 `UP`이었다.

실행 로그는 빌드 산출물 경로 `android/app/build/ui-followup-landscape.txt`, `ui-followup-regression.txt`, `ui-followup-live.txt`, `ui-followup-home-capture.txt`에 둔다. 해당 파일은 저장소 증빙 이미지와 별도로 관리한다.

## 남은 확인과 한계

- 러닝 서버 검사에는 Debug 예시 GPS를 사용했다. GPS 끊김·일시정지·재개·저장 실패 시 입력 보존은 합성 상태로 점검했다. 야외 실제 위치 수집·경로 정확도·백그라운드 장시간 추적은 별도 현장 검증이 필요하다.
- 이번 실행에는 유료 외부 AI 호출을 포함하지 않았다. 외부 AI 실기기 테스트는 1회 호출 승인 옵션을 요구하며, 이번 후속 점검에서는 실행하지 않았다. 실제 외부 판독·사진 업로드의 새 검증 결과로 간주하지 않는다.
- 접근성 점검은 선택한 화면의 큰 글자·버튼/입력 접근과 Compose semantics 동작 범위다. TalkBack 실제 음성·포커스 순서, 모든 화면의 가로·키보드·팝업 조합은 완료하지 않았다.
- 가로 화면에서 큰 글자와 키보드를 동시에 사용하는 운동 편집은 이번 새 검사에 포함하지 않았다. 새 운동 검사는 기본 글자 크기, 새 홈 검사는 글자 2배다.
