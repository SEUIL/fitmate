# FitMate 발표 시연 순서와 핵심 키워드

- 작성일·최종 수정일: 2026-09-17
- 버전: v1.0
- 상태: 검토 중
- 기준: 현재 앱과 준비된 발표용 데이터
- 권장 시간: 시연 14분 + 화면 전환·대기 여유 1분

## 발표의 중심 문장

> FitMate는 운동을 계획하고 기록하며, 변화를 확인하고 함께 운동할 사람까지 연결하는 앱입니다.

**홈 → 헬스 → 러닝 기록 → 인바디 → 운동 리포트 → 메이트 → 커뮤니티·DM → 운영자 센터 → 마무리**

## 시연 순서

| 순서·시간 | 화면에서 할 일 | 청중에게 전달할 핵심 | 어필 키워드 |
|---|---|---|---|
| **1. 홈 · 30초** | 로그인된 홈에서 헬스 10회·러닝 4회와 주요 메뉴를 보여 준다. | 개인 운동과 소셜 활동을 한곳에서 관리한다. | **통합 관리 · 누적 기록** |
| **2. 헬스 · 3분** | `운동 시작`에서 지원 종목을 짧게 보여 준다. 헬스에서 루틴 하나를 펼치고, `새 루틴 만들기`의 운동 소개를 확인한 뒤 닫는다. 준비한 루틴으로 시작해 애니메이션 → 세트 1개 기록 → 휴식 → 종료·저장을 보여 준다. | 루틴 선택부터 운동 안내와 세트 기록까지 자연스럽게 이어진다. | **루틴 접기·펴기 · 운동 가이드 · 세트 기록 · 휴식 타이머** |
| **3. 러닝·Samsung Health · 1분 30초** | 운동 기록의 `러닝` 필터 → **9월 13일 기록**을 연다. 4km·25분·랩을 보고, 아래 Samsung Health 요약과 심박·페이스 분석을 보여 준다. | 직접 기록한 운동과 연결된 건강 데이터를 함께 확인한다. | **종목별 기록 · 랩·페이스 · 심박 분석 · 데이터 연결** |
| **4. 인바디 · 1분** | 인바디 기록에서 날짜별 체성분 변화를 보여 준다. 사진 판독·검수는 리허설에서 준비한 결과 화면으로 짧게 설명한다. | 운동량뿐 아니라 몸의 변화도 기록하고, 판독값은 사용자가 확인한다. | **체성분 추이 · 사진 판독 · 사용자 검수** |
| **5. 운동 리포트 · 2분** | 운동 기록 → **9월 11일 헬스 기록** → 리포트 해석으로 이동한다. 최근 4주 범위, 인바디·Samsung Health 포함 옵션과 준비된 결과의 요약·다음 운동 제안을 보여 준다. | 한 번의 기록을 넘어 누적 운동과 체성분을 다음 운동의 참고 정보로 연결한다. | **누적 기록 분석 · AI 해석 옵션 · 다음 운동 제안** |
| **6. 메이트 · 2분** | 메이트에서 종목·지역 필터 → 준비된 모집글 상세 → 문의 대화 → 참가 상태를 순서대로 보여 준다. | 운동 조건을 비교하고, 문의와 참가 신청으로 실제 약속을 준비한다. | **조건 검색 · 모집·참가 · 문의 채팅 · 함께 운동** |
| **7. 커뮤니티·DM · 1분 30초** | 커뮤니티의 팔로잉·내 게시물에서 준비된 글과 댓글을 보여 준다. DM으로 이동해 상대 이름·마지막 메시지와 기존 대화방을 확인한다. | 운동 경험을 공유하고 사람 간 대화로 이어진다. | **운동 경험 공유 · 팔로잉 피드 · 댓글 · 개인 대화** |
| **8. 운영자 센터 · 2분** | `프로필 → 설정 → 운영자 센터`에서 신고 상세와 관련 회원·콘텐츠를 확인한다. 이의신청의 접수·검토 중·수용·기각 상태를 보여 준다. 남은 시간에 공지·운영 규칙·운영자 권한 목록을 짧게 확인한다. | 사용자 기능뿐 아니라 신고 검토와 재심, 서비스 운영까지 고려했다. | **신고·제재 · 이의신청 · 처리 이력 · 역할별 권한** |
| **9. 마무리 · 30초** | 홈으로 돌아와 조작을 멈추고 중심 문장을 정리한다. | 운동의 계획·기록·분석·소통을 연결하는 것이 핵심이다. | **운동의 지속성 · 연결된 사용자 경험** |

## 조작은 짧게, 결과는 확실하게

- **현장 입력은 헬스 세트 1개만:** 예를 들어 벤치프레스 `40kg × 10회, RPE 7`. 짧은 기능 시연이라고 설명하고 종료한다.
- **분석은 준비된 기록으로:** 방금 끝낸 짧은 운동 대신 9월 11일 헬스와 9월 13일 러닝을 사용한다. 홈의 10회·4회는 시연 시작 전 기준이며, 새 헬스를 저장하면 횟수가 늘어난다.
- **다종목은 선택 화면에서 소개:** 배드민턴·클라이밍·등산·골프를 모두 실행하지 않는다. 시간이 남으면 배드민턴의 종목별 입력 화면 하나만 추가로 보여 준다.
- **운영자 화면은 기존 사례 조회 중심:** 발표 중 제재·이의신청 결과를 바꾸지 않고, 연결된 신고와 처리 이유를 설명한다.

## 발표 직전 확인할 것

- 최신 앱·백엔드·DB 연결, 발표 계정 로그인과 운영자 센터 접근을 확인한다.
- **AI 결과를 구분한다.** 현재 준비된 9월 11일 결과는 `기록 기반 기본 해석`이다. AI를 강조하려면 리허설에서 외부 전송 동의 후 실제 AI 생성 결과를 확인해 준비한다. 기본 해석을 AI 생성 결과로 소개하지 않는다.
- **Samsung Health 수치는 발표용 합성 데이터**라고 한 번 안내한다. 저장 요약·분석 시연이며, 현장에서 Fit3가 측정하거나 동기화한 데이터는 아니다.
- 인바디 판독과 AI 생성이 지연되면 준비된 완료 결과로 이동한다. 인바디 판독 완료 화면을 준비하지 못했다면 저장된 체성분 변화만 보여 준다.
- 기존 메이트 모집글·문의방이 열리는지 확인하고, 방해 금지와 화면 회전 고정을 설정한다.

## 시간이 부족할 때

**유지:** 헬스 1세트 저장 → 연결된 운동 리포트 → 메이트 → 신고·이의신청.

**축소:** 새 루틴 소개, 인바디 판독 과정, 댓글 입력, 공지·운영 규칙·권한 목록. 회원가입과 설정 전체 설명은 본 시연에서 생략한다.
